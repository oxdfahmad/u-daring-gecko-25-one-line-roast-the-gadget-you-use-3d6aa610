One original line roasting the gadget I reach for every day: the wireless
earbud that always dies mid-call. `main.py` holds the roast as a constant,
gates it (1–200 chars, exactly one line, non-blank), writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads the file back and verifies the
bytes match, printing a short confirmation. Stdlib only, no network, no
input — every run writes the same bytes.

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
